# DND — Holmes Halloween: Chandramukhi Mansion

A Tamil cinema-inspired haunted-mansion adventure for a Halloween game night.

## Playable prototype
Open `index.html` in a browser. Choose one of five Chandramukhi-inspired characters, explore rooms, collect clues, solve a riddle, and reach one of two endings.

## Publish with GitHub Pages
Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. When deployment finishes, GitHub provides a website URL.
